# HarEvent: Event & Vendor Listing Homepage

A responsive, frontend-only homepage for **HarEvent**, an event-planning platform where users can discover trusted vendors for weddings and other celebrations.

**Live Demo:** https://harikapatoju66-cmd.github.io/harevent/
**Repository:** https://github.com/harikapatoju66-cmd /harevent

## Features

- Sticky header with responsive hamburger menu
- Hero banner with Event / Vendor Category / City search
- Working search and filter using sample frontend data
- Clickable vendor and event category cards that filter the results
- "View All Vendors" and "View All Events" buttons
- "How HarEvent Works" four-step section
- "Why Choose HarEvent" highlights
- Blog section, CTA banner, and 5-column footer
- Login modal (Vendor / Customer), demo only with no real authentication
- Floating WhatsApp click-to-chat button
- Fully responsive on desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, CSS variables, media queries)
- Vanilla JavaScript (ES6)
- Google Fonts (Playfair Display, Poppins)

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/harevent.git
   ```
2. Open the folder:
   ```bash
   cd harevent
   ```
3. Open `index.html` in your browser. No build step or dependencies are needed.

## Notes

- This is a frontend-only project. There is no backend, API, database, or real authentication.
- Vendor data is sample data stored in `script.js`.
- Images are from [Unsplash](https://unsplash.com).
